# Made Clear Smart

Landing page for an AI video SaaS, in Made Clear Studios colours. Copy is lorem ipsum for now.

Plain static site, no build step. Netlify serves the repo root (`netlify.toml`).

- `index.html`: all sections
- `css/styles.css`: brand tokens at the top (black, white, yellow #FFFF00)
- `js/main.js`: mobile menu, product mock, form placeholder
- `images/`: MCS logos

Preview locally: `python3 -m http.server 8080`
